# 游戏数据维护说明

本目录的数据会被游戏模块直接 import 读取，修改后刷新浏览器即可生效。

- `economy.js`：城市、矿山、农场的固定每日收益。
- `battleRewards.js`：战斗胜利结算的金币和经验随机范围。
- `units.js`：军种基础属性、招募费用、维护费，以及不同等级的属性和升级花费。
- `generals.js`：非玩家将领按势力随机生成的属性范围。玩家将领属性来自玩家自己的属性加点。
- `factionGrowth.js`：不同势力的随机成长曲线范围。

范围字段统一使用 `{ min, max }`。例如 `{ min: 10, max: 20 }` 表示游戏运行时会在 10 到 20 之间随机取值。
