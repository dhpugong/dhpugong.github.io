# 游戏项目

当前保留两个可体验项目：AI 贪吃蛇和策略 RPG《铁冠诸侯》。

## 贪吃蛇

AI 贪吃蛇支持手动游玩和多种 AI 策略，包含难度、墙体模式、皮肤、音效和 AI 评分记录。

## RPG

《铁冠诸侯》是像素风策略 RPG，包含大陆探索、自动战斗、招募扩军、攻城收税和存档。

## 本地运行

项目使用原生 HTML、CSS、Canvas 和 ES Modules，不需要安装依赖或打包。

在仓库根目录启动静态服务器：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8000/
http://127.0.0.1:8000/snake/
http://127.0.0.1:8000/strategy-rpg/
```
